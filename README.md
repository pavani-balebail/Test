# Test

## Search Page

A simple search page with a text box and search button that displays mock data results.

### Features
- Clean, modern UI with gradient background
- Responsive search box and button
- Mock data generation for search results
- Smooth animations and hover effects
- Enter key support for quick searching

### Usage
1. Open `search.html` in your web browser
2. Type a search term in the text box
3. Click the "Search" button or press Enter
4. View the generated mock results

### Implementation
The search page is built with vanilla HTML, CSS, and JavaScript:
- **HTML**: Structure with search input, button, and results container
- **CSS**: Modern styling with gradients and animations
- **JavaScript**: Mock data generation and dynamic result display
